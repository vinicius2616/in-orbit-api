# 🚀 In Orbit API

API desenvolvida durante a **NLW Pocket** da [Rocketseat](https://www.rocketseat.com.br/), com foco em aprendizado prático de construção de APIs modernas utilizando o ecossistema Node.js e TypeScript.

## 🛠️ Tecnologias Utilizadas

- **TypeScript** — Tipagem estática para JavaScript, proporcionando maior segurança e escalabilidade.
- **Drizzle ORM** — Mapeamento objeto-relacional moderno e eficiente para interações com o banco de dados.
- **Docker & Docker Compose** — Containerização da aplicação para facilitar o ambiente de desenvolvimento e deployment.
- **Node.js** — Ambiente de execução para JavaScript no servidor.
